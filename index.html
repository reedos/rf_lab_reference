Assumptions

  • ZPNA is fixed at 50 Ω (analyzer port). ZDUT is the DUT impedance at that plane (per side if differential).
  • PNA → DUT: dBm is available source power. VOPP is the loaded voltage at the DUT. Type VOPP to get the PNA source setting.
  • DUT → PNA: dBm is delivered receiver power. VOPP is the voltage at the PNA port (same node as the DUT output if connected directly). Type VOPP to get the receiver reading.
  • Real impedances. Vload = 2√(Pavs ZS) · ZL / (ZS + ZL).
  • Differential: complementary 180°. VOPP is V+ − V−. Zdiff = 2 · Z (per side).

Formulas

Γ = (ZL − ZS) / (ZL + ZS)
Voc = 2 √(Pavs · ZS)
Vrms = Voc · ZL / (ZS + ZL)
VOPP = 2√2 · Vrms  (sine)
PNA→DUT: ZS=ZPNA, ZL=ZDUT, dBm = Pavs
DUT→PNA: ZS=ZDUT, ZL=ZPNA, dBm = Pdel

Arrow up/down on dBm steps 1 dB. Hold Shift for 0.1 dB.
