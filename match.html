Mismatch loss is the power not delivered to a passive load: −10 log10(1 − |Γ|²). It is not the same as return loss.

Formulas

|Γ| = 10(−RL/20)
VSWR = (1+|Γ|) / (1−|Γ|)
RL = −20 log10|Γ|
ML = −10 log10(1 − |Γ|²)

For a balanced DUT, use mixed-mode Sdd11 the same way you would use S11.

Bench notes

  • 20 dB RL ≈ VSWR 1.22. Fine for most small-signal S-params.
  • 10 dB RL ≈ VSWR 1.92. Mismatch loss ~0.46 dB — already shows up in power accuracy.
  • A 6 dB pad on a badly matched DUT both protects the VNA and improves apparent match.
  • Source match and load match both eat into the uncertainty of a power measurement.
