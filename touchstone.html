Model and limits

Touchstone 1 files only, S-parameters, MA, DB or RI form, one reference impedance for every port. Reading is at the nearest point in the file; nothing is interpolated. Mixed-mode conversion assumes both lines of a pair share the file's reference. The voltage gain uses the file's reference for each side of the DUT card's topology, doubled for a differential side, and the terminal-referred form uses the file's input reflection at the same point.

The file is read in this browser and discarded when the page closes. The link keeps the frequency, the mapping and the plot choice, not the file.
